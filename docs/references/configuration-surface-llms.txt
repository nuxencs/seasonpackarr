seasonpackarr configuration surface reference

- config contract spans internal defaults, config.yaml, runtime loading, and schemas/config-schema.json
- clients can point host directly at a qBittorrent Web API endpoint or at a qui reverse-proxy URL; with qui proxy auth, leave username/password/apiKey empty
- high-signal settings:
  - host
  - port
  - apiToken
  - clients.<name>.host/port/username/password/apiKey/preImportPath
  - clients.<name>.qbit.category/savePath/tags/pausedOnAdd/contentLayout
  - clients require qbit.category or qbit.savePath
  - qbit.contentLayout is optional; unset defers to qBittorrent defaults
  - smartMode
  - smartModeThreshold
  - fuzzyMatching.skipRepackCompare
  - fuzzyMatching.simplifyHdrCompare
  - metadata.tvdbAPIKey
  - metadata.tvdbPIN
  - notifications
- any config behavior change should update docs and schema together
