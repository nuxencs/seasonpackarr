seasonpackarr operations and verification reference

- primary local check: go test -v ./...
- security check: govulncheck ./...
- formatting for Go changes: gofumpt -w .
- smoke flows:
  - go run . start --config <dir>
  - go run . test candidate "<release>" --client "<name>" --host 127.0.0.1 --port 42069 --api "<token>"
  - go run . test match "<release-or-torrent>" --client "<name>" --host 127.0.0.1 --port 42069 --api "<token>"
  - go run . test import "<release-or-torrent>" --client "<name>" --host 127.0.0.1 --port 42069 --api "<token>" (mutating: creates hardlinks and imports the torrent)
- if E2E cannot run because external services or credentials are missing, say that explicitly

Prowlarr backfill:
- Search-only preview (no torrent downloads): go run . search --dry-run --api <token> [--client <name>]
- Exact preview: go run . search --dry-run --verify --api <token> [--client <name>]
- Import: go run . search --api <token> [--client <name>]
- All three modes call the running service. --url selects its base URL.
- Episode variants with a compatible pack in the same client are excluded before tracker queries. coveredEpisodeTorrents reports excluded torrent entries; other variants and independent clients remain eligible.
- Schedule: search.interval is 0s by default; set a duration such as 24h to opt in.
- Checks: go test ./internal/prowlarr ./internal/http ./internal/config ./cmd
- Contract and limits: docs/product-specs/prowlarr-backfill.md
